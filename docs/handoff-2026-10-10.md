## 1. 项目是什么

一个**单向位置分享 + 一封信 + 一些影像**的个人网站：业主的手机定期上报位置，访客打开网址、输入 6 位访问码后，
可以看业主的位置、读一封信、看一些影像；访客的位置不会被采集，业主也不会收到访问通知。

流程：

1. 业主 iPhone 上的 OwnTracks（约 15 分钟一次）用独立账号密码把位置 POST 到 HTTPS 上报端点；
2. nginx 把上报请求转给定位容器（OwnTracks Recorder），位置以 JSON 存在服务器磁盘；
3. 访客浏览器打开网站，nginx 转给 Python 标准库服务 `app.py`：
   页面由 `static/` 下的文件提供，数据走 `/api/*`，影像走 `/media/*`（支持分段请求）。

## 4. 接口契约（摘要）

完整说明见 `docs/frontend-contract.md`，要点：

| 接口 | 登录 | 说明 |
|---|---|---|
| `POST /api/login` | 否 | 提交 6 位访问码；成功后服务器下发 `loc_auth` Cookie（HttpOnly） |
| `GET /api/state` | 是 | 返回 `lat / lon / tst / batt / stopped / has_location` |
| `GET /api/videos` | 是 | 返回 `name / title / size / url / type / caption / recorded`，按拍摄时间倒序 |
| `GET /media/<文件名>` | 是 | 支持 `Range` 请求（iPhone 播放和拖动进度必需） |
| `POST /api/owner_login`、`POST /api/owner_action` | 业主 | 控制台登录与停止/恢复共享 |
| `GET /` `/new` | 否 | 新版首页；`/legacy` 为旧版首页 |
| `GET /map` | 是 | 完整地图页（未登录 302 回首页） |

**前端必须遵守**：不在前端判断访问码；不引入外部 CDN 或统计脚本；不请求访客定位；保留 `noindex`。

## 5. 本地运行与部署

本地运行（无需第三方依赖）：

```bash
cd <项目目录>
LOCAPP_BASE="$PWD" \
LOCAPP_STORE="$PWD/work/local-run/store" \
LOCAPP_SECRET_FILE="$PWD/work/local-run/secret" \
LOCAPP_MEDIA="$PWD/media" \
FRIEND_CODE=213000 OWNER_PASS=local-owner \
python3 app.py
```

部署到服务器（把 `app.py` 与 `static/` 推上去并重启服务；脚本会处理子目录）：

```bash
bash <migrate-kit>/deploy.sh ubuntu@<server>
```

验收：首页 / 控制台 / 访问码登录 / 位置 / 证书 / 上报通道六项；建议再用无头浏览器做一次真实点击与滑动验证。

测试：

```bash
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/anchor-core.test.js tests/experience-core.test.js tests/experience-controller.test.js tests/map.test.js
```

## 6. 影像上传流程（工具化）

1. 业主把视频放进桌面上的上传文件夹；
2. 先跑 `python3 tools/upload_videos.py --dry-run` 看要做什么；
3. 去掉 `--dry-run` 执行：跳过已上传的（按**拍摄时间**比对）→ 压缩到网页友好大小 → 上传 → 写入拍摄时间与文案；
4. 文案来源优先级：同名 `.txt` > 文件夹里的 `文案.txt`（一行一条 `文件名 | 文字`）> 文件名里的文字 > 只有拍摄时间。

注意：转码会丢失原始拍摄时间，因此拍摄时间单独记录在服务器的 `media/captions.json` 中。
